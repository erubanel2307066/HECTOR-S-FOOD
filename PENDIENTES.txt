PENDIENTE: MIGRACIÓN A SUPABASE
========================================================

ESTO LO TIENES QUE HACER TÚ (pasos manuales):

1. Crear cuenta en https://supabase.com
2. Crear un proyecto nuevo (elegir región más cercana)
3. Ir a Settings > Database > Connection string
   → Copiar la URI completa (la que usa el pooler, puerto 6543)
4. Ir a Storage > Create bucket
   → Nombre: "menu-images"
   → Marcar como PÚBLICO
5. Ir a Settings > API y copiar:
   → Project URL (algo como https://xxxxx.supabase.co)
   → anon public key
   → service_role secret key
6. En el dashboard de Supabase ir a SQL Editor y correr:
   npx prisma migrate deploy
   (esto crea las tablas en Supabase)
7. Correr el seed para datos iniciales:
   npm run seed
